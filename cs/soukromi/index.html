Zásady ochrany soukromí

Tyto zásady platí pro aplikaci Zloťák pro Android a pro web https://moszole.github.io/zlotak/. Provozovatelem je toszo (https://github.com/toszo).

Neshromažďujeme žádné osobní údaje. Aplikace nemá uživatelské účty, nevyžaduje přihlášení a nepracuje s polohou ani s kontakty.

Všechna vaše data zůstávají v zařízení. Nákupní seznam, nastavení a ruční kurz se ukládají jen lokálně v aplikaci a nikam se neodesílají. Smazat je můžete v nastavení aplikace nebo odinstalováním aplikace.

Aplikace se připojuje pouze k serveru moszole.github.io. Odtud stahuje katalog akčních nabídek a obrázky produktů. Požadavek neobsahuje žádný váš identifikátor ani obsah vašeho seznamu. GitHub jako poskytovatel hostingu může ukládat běžné logy serveru (například IP adresu a čas požadavku) podle vlastních zásad ochrany osobních údajů GitHubu. K těmto logům nemáme přístup.

Nepoužíváme cookies, analytiku, reklamy ani služby pro hlášení chyb. Web ani aplikace nenačítají obsah od třetích stran.

Obrázky produktů pocházejí z našeho serveru moszole.github.io, aplikace je nestahuje od obchodních řetězců ani z jiných služeb.

Dotazy a žádosti můžete zaslat jako veřejné hlášení na https://github.com/moszole/zlotak/issues. Změny těchto zásad zveřejníme na této stránce.
